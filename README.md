# drumsynth

Ahora el proyecto está separado en **6 plugins LV2 independientes**:
- Kick
- Snare
- Hi-hat
- Tom
- Clap
- Sub/808

Cada plugin incluye parámetros de diseño:
- Tone
- Pitch
- Amp Decay
- Amp Release
- Filter Decay
- Filter Release
- Resonance
- Drive
- MIDI In + Gate

## Build
```bash
make
```

## ARM64
```bash
make arm64
```
